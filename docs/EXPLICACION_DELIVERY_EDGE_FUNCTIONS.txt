  GUÍA Y EXPLICACIÓN TÉCNICA: INTEGRACIÓN DE DELIVERY (RAPPI CARGO & UBER DIRECT)
  Y CONFIGURACIÓN DE SUPABASE EDGE FUNCTIONS PARA TRAGALERO
================================================================================

1. ARQUITECTURA GENERAL
--------------------------------------------------------------------------------
La solución de Delivery en Tragalero se compone de 3 capas principales:

1. Interface Administrativa (`admindelivery.html`):
   - Permite a los usuarios con rol 'Owner' configurar las llaves y estados de
     sus cuentas de Rappi Cargo y Uber Direct.
   - Ofrece un panel lateral deslizante (Drawer) para que los usuarios con roles
     de administración ('Admin', 'Developer', 'CS', 'Ventas') puedan cambiar el
     contexto entre diferentes cuentas de clientes (por ejemplo, "Salsita",
     "Clamatos") y configurar o probar de forma independiente el servicio de
     delivery de cada restaurante.

2. Base de Datos Supabase (`tragalero_delivery_config`):
   - Almacena de forma persistente y segura las credenciales (Client ID,
     Client Secret, Store ID / Customer ID, entorno sandbox/producción y estado)
     de cada negocio vinculadas a su `user_id`.

3. Supabase Edge Function (`delivery-service`):
   - Se encarga de procesar las peticiones hacia las APIs externas de Rappi Cargo
     y Uber Direct en el servidor para proteger las credenciales secretas
     (Client Secret) y evitar bloqueos por CORS en el navegador.


2. PASO 1: CREAR LA TABLA EN SUPABASE SQL EDITOR
--------------------------------------------------------------------------------
Copia y ejecuta el siguiente script SQL en tu panel de Supabase:
(Menú SQL Editor -> New Query -> Run)

--------------------------------------------------------------------------------
-- TABLA DE CONFIGURACIÓN DE DELIVERY PARA TRAGALERO
--------------------------------------------------------------------------------
CREATE TABLE IF NOT EXISTS public.tragalero_delivery_config (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id UUID REFERENCES public.usuarios(id) ON DELETE CASCADE UNIQUE,
    rappi_client_id TEXT,
    rappi_client_secret TEXT,
    rappi_store_id TEXT,
    rappi_env TEXT DEFAULT 'sandbox',
    rappi_enabled BOOLEAN DEFAULT FALSE,
    uber_customer_id TEXT,
    uber_client_id TEXT,
    uber_client_secret TEXT,
    uber_env TEXT DEFAULT 'sandbox',
    uber_enabled BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Habilitar Seguridad a Nivel de Fila (RLS)
ALTER TABLE public.tragalero_delivery_config ENABLE ROW LEVEL SECURITY;

-- Políticas de acceso
DROP POLICY IF EXISTS "Owner manage delivery config" ON public.tragalero_delivery_config;
CREATE POLICY "Owner manage delivery config" ON public.tragalero_delivery_config
    FOR ALL USING (auth.uid() = user_id OR public.check_is_admin());
--------------------------------------------------------------------------------


3. PASO 2: DÓNDE PONER LAS APIS Y LA EDGE FUNCTION EN SUPABASE
--------------------------------------------------------------------------------
Para configurar las APIs en Supabase:

A) En el Panel de Supabase Dashboard:
   1. Ve a "Edge Functions" en la barra lateral izquierda.
   2. Haz clic en "Create a new function" y asígnale el nombre: `delivery-service`
   3. Pega el código TypeScript que se proporciona a continuación en `index.ts`.
   4. Guarda y despliega la función ("Deploy").

B) Código completo de la Edge Function (`delivery-service/index.ts`):

```typescript
import { serve } from "https://deno.land/std@0.168.0/http/server.ts";
import { createClient } from "https://esm.sh/@supabase/supabase-js@2";

const corsHeaders = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Headers": "authorization, x-client-info, apikey, content-type",
};

serve(async (req) => {
  if (req.method === "OPTIONS") {
    return new Response("ok", { headers: corsHeaders });
  }

  try {
    const { action, provider, user_id, provider_config, pickup_address, dropoff_address } = await req.json();

    const supabaseUrl = Deno.env.get("SUPABASE_URL") ?? "";
    const supabaseKey = Deno.env.get("SUPABASE_SERVICE_ROLE_KEY") ?? "";
    const supabase = createClient(supabaseUrl, supabaseKey);

    // Obtener credenciales del cliente desde la base de datos si no vienen en el body
    let config = provider_config;
    if (!config && user_id) {
      const { data } = await supabase
        .from("tragalero_delivery_config")
        .select("*")
        .eq("user_id", user_id)
        .single();
      config = data;
    }

    // 1. PROBAR CONEXIÓN O AUTENTICAR RAPPI CARGO
    if (action === "test_rappi") {
      const isProd = config?.env === "production";
      const rappiBaseUrl = isProd
        ? "https://microservices.rappi.com/main-gateway/fmk/api/v1"
        : "https://microservices.dev.rappi.com/main-gateway/fmk/api/v1";

      const authRes = await fetch(`${rappiBaseUrl}/oauth/token`, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          client_id: config?.client_id || config?.rappi_client_id,
          client_secret: config?.client_secret || config?.rappi_client_secret,
          grant_type: "client_credentials",
        }),
      });

      const authData = await authRes.json();
      if (!authRes.ok) {
        return new Response(
          JSON.stringify({ success: false, message: authData.message || "Error al autenticar con Rappi Cargo" }),
          { headers: { ...corsHeaders, "Content-Type": "application/json" } }
        );
      }

      return new Response(
        JSON.stringify({ success: true, message: "Conexión con Rappi Cargo exitosa", token: authData.access_token }),
        { headers: { ...corsHeaders, "Content-Type": "application/json" } }
      );
    }

    // 2. PROBAR CONEXIÓN O AUTENTICAR UBER DIRECT
    if (action === "test_uber") {
      const uberAuthUrl = "https://login.uber.com/oauth/v2/token";
      const params = new URLSearchParams({
        client_id: config?.client_id || config?.uber_client_id,
        client_secret: config?.client_secret || config?.uber_client_secret,
        grant_type: "client_credentials",
        scope: "eats.deliveries",
      });

      const authRes = await fetch(uberAuthUrl, {
        method: "POST",
        headers: { "Content-Type": "application/x-www-form-urlencoded" },
        body: params.toString(),
      });

      const authData = await authRes.json();
      if (!authRes.ok) {
        return new Response(
          JSON.stringify({ success: false, message: authData.error_description || "Error al autenticar con Uber Direct" }),
          { headers: { ...corsHeaders, "Content-Type": "application/json" } }
        );
      }

      return new Response(
        JSON.stringify({ success: true, message: "Conexión con Uber Direct exitosa", token: authData.access_token }),
        { headers: { ...corsHeaders, "Content-Type": "application/json" } }
      );
    }

    // 3. OBTENER COTIZACIÓN DE ENVÍO (MOCK / REAL GATEWAY)
    if (action === "get_quote") {
      return new Response(
        JSON.stringify({
          success: true,
          provider: provider,
          estimated_cost: provider === "rappi" ? 45.00 : 52.50,
          currency: "MXN",
          pickup: pickup_address,
          dropoff: dropoff_address,
          eta_minutes: provider === "rappi" ? 25 : 20,
        }),
        { headers: { ...corsHeaders, "Content-Type": "application/json" } }
      );
    }

    return new Response(
      JSON.stringify({ success: false, message: "Acción no reconocida" }),
      { headers: { ...corsHeaders, "Content-Type": "application/json" } }
    );
  } catch (err) {
    return new Response(
      JSON.stringify({ success: false, error: err.message }),
      { status: 400, headers: { ...corsHeaders, "Content-Type": "application/json" } }
    );
  }
});
```


4. FUNCIONAMIENTO DEL PANEL DE CLIENTES (NAVEGACIÓN MULTI-CUENTA)
--------------------------------------------------------------------------------
- Para el Usuario Dueño ('Owner'):
  Al ingresar a `admindelivery.html`, el sistema detecta su `user_id` e incluye
  únicamente sus credenciales propias. El menú lateral de clientes se oculta.

- Para Administradores y Equipo ('Admin', 'Developer', 'CS', 'Ventas'):
  Aparece la pestaña lateral "CLIENTES" (`sidebar-container`). Al dar clic en ella,
  se despliega la lista completa de restaurantes o usuarios (p. ej. "Salsita",
  "Clamatos"). Al hacer clic en cualquiera de ellos:
  1. `activeOwnerId` se actualiza al ID del cliente seleccionado.
  2. La función `loadDeliveryConfig(activeOwnerId)` realiza un selector a
     `tragalero_delivery_config` buscando el registro de dicho cliente.
  3. Los campos de Rappi Cargo y Uber Direct se rellenan automáticamente con la
     configuración específica de ese cliente.
  4. Al guardar cambios o ejecutar pruebas de cotización, las credenciales
     se guardan y prueban de forma independiente para ese cliente específico.
