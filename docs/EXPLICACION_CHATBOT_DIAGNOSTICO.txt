================================================================================
  EXPLICACIÓN TÉCNICA Y DIAGNÓSTICO DEL CHATBOT Y LA EDGE FUNCTION CON OPENAI
================================================================================

1. ¿POR QUÉ APARECÍAN MENSAJES PREFABRICADOS ("¡LISTO! MENÚ ACTUALIZADO")?
--------------------------------------------------------------------------------
- El archivo `docs/assets/js/tragaleroChatbot.js` incluía un sistema de reserva
  (fallback) con expresiones regulares en Javascript dentro del navegador.
- Cuando la Edge Function de Supabase no respondía (por falta de conexión,
  error de CORS o porque la llamada fallaba silenciosamente), el código del frontend
  ejecutaba automáticamente la lógica fallback en Javascript y devolvía las frases
  preconfiguradas fijas.
- Además, en esa simulación cliente se estaba intentando actualizar el usuario
  activo sin sincronizar el contexto seleccionado del negocio en `adminMenus.html`
  (cuando se administraba otro proyecto desde la barra lateral), provocando que
  el cambio se guardara en el perfil general y no se visualizara en la interfaz.


2. CÓMO HACER QUE LA INTELIGENCIA ARTIFICIAL DE OPENAI RESPONDA DIRECTAMENTE
--------------------------------------------------------------------------------
Para que sea OpenAI el que razone la orden del usuario y ejecute la herramienta:

A) La Edge Function `ai-assistant` debe procesar el mensaje con GPT-4o-mini usando
   Function Calling (`tools`).
B) La Edge Function consulta el menú almacenado en Supabase, ejecuta la edición
   del JSON (`config.categories`) en la base de datos y le devuelve la respuesta
   generada por OpenAI al frontend.
C) El frontend debe recibir la respuesta de la Edge Function (`data.reply`) y
   mostrarla directamente sin interceptarla con frases duras.


3. CÓMO SUBE IMÁGENES EL CLIENTE EN EL CHATBOT
--------------------------------------------------------------------------------
- En la barra de entrada del chatbot (esquina inferior derecha) se encuentra el
  ícono de clip (`bi-paperclip`).
- Al presionar el clip, el usuario selecciona una imagen de su dispositivo.
- El archivo se sube automáticamente a Cloudinary y su URL pública se adjunta
  a la solicitud enviada a OpenAI/Supabase para crear la tarea en `adminTask.html`.


4. QUÉ SE DEBE REVISAR EN SUPABASE PARA EL FUNCIONAMIENTO COMPLETO
--------------------------------------------------------------------------------
1. Verificar que el secreto `OPENAI_API_KEY` esté configurado en:
   Supabase -> Project Settings / Edge Functions -> Secrets.
2. Confirmar que la Edge Function `ai-assistant` esté desplegada y activa.
3. Asegurar que el usuario autenticado en la sesión tenga un menú existente en la
   tabla `tragalero_menus` para el `user_id` correspondiente.
