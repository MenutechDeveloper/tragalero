============================================================
RESUMEN DE INTEGRACIÓN DE PAGOS EN LÍNEA (STRIPE & MERCADO PAGO)
============================================================

1. ¿CÓMO FUNCIONA?
- Cada cliente (restaurante) conecta su propia cuenta mediante OAuth con un clic ("Conectar Stripe" / "Conectar Mercado Pago") desde `onlinePayment.html`.
- NUNCA se piden API Keys ni secretos en los formularios del frontend. Todo el dinero va directo a las cuentas de cada restaurante.
- En el menú digital (`menu.html` / `menutechUI.js`), al momento de pagar, la Edge Function redirige al comensal a la pasarela de Stripe o Mercado Pago del restaurante correspondiente.
- Una vez pagado, los webhooks actualizan el estado del pedido en `tragalero_orders` a 'Aprobado'.

2. LO ÚNICO QUE TIENES QUE HACER TÚ (SQL SETUP):
- Ejecuta el script SQL en el Editor SQL de Supabase: `docs/setup_payment_tables.sql`.
- Configura la Edge Function de Supabase `payment-service` siguiendo la guía en `docs/EDGE_FUNCTION_PAYMENTS.txt`.

============================================================
ARCHIVOS CREADOS / MODIFICADOS:
- `docs/onlinePayment.html` -> Módulo de configuración de pasarelas de pago.
- `docs/setup_payment_tables.sql` -> Tablas y columnas de pagos.
- `docs/EDGE_FUNCTION_PAYMENTS.txt` -> Código backend de la Edge Function para OAuth, checkout y webhooks.
- `docs/menutechUI.js` -> Flujo de checkout de pago en línea para el comensal.
