1. ¿HACE FALTA EJECUTAR CÓDIGO SQL EN SUPABASE?
--------------------------------------------------------------------------------
¡SÍ, TOTALMENTE! Para que Supabase pueda guardar la información, llaves y estados
de Rappi Cargo y Uber Direct para CADA restaurante (Salsita, Clamatos, etc.),
DEBES ejecutar este código SQL en el panel de Supabase:

Copia y pega esto en: Supabase Dashboard -> SQL Editor -> New Query -> Run:

```sql
-- CREAR TABLA DE CONFIGURACIÓN DE DELIVERY MULTI-RESTAURANTE
CREATE TABLE IF NOT EXISTS public.tragalero_delivery_config (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    user_id UUID REFERENCES public.usuarios(id) ON DELETE CASCADE UNIQUE,
    rappi_client_id TEXT,
    rappi_client_secret TEXT,
    rappi_store_id TEXT,
    rappi_env TEXT DEFAULT 'sandbox',
    rappi_enabled BOOLEAN DEFAULT FALSE,
    uber_customer_id TEXT,
    uber_client_id TEXT,
    uber_client_secret TEXT,
    uber_env TEXT DEFAULT 'sandbox',
    uber_enabled BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- Habilitar Seguridad (RLS)
ALTER TABLE public.tragalero_delivery_config ENABLE ROW LEVEL SECURITY;

-- Política de Acceso (Solo el dueño o los Admins de Tragalero pueden gestionar)
DROP POLICY IF EXISTS "Owner manage delivery config" ON public.tragalero_delivery_config;
CREATE POLICY "Owner manage delivery config" ON public.tragalero_delivery_config
    FOR ALL USING (auth.uid() = user_id OR public.check_is_admin());
```


2. ¿CÓMO MANEJAN RAPPI CARGO Y UBER DIRECT MÚLTIPLES RESTAURANTES?
--------------------------------------------------------------------------------
Tanto Rappi Cargo como Uber Direct permiten dos modelos de negocio:

A) MODELO CON CUENTA MAESTRA DE TRAGALERO (Recomendado si tú cobras el servicio):
   - Tú como Tragalero tienes UNA sola API Key/Client Secret Maestra (Master Account)
     con Rappi y Uber.
   - Cada restaurante nuevo que se registra (Salsita, Clamatos, etc.) solo necesita:
     * En Rappi Cargo: Su `Store ID` (ID de Sucursal) registrado bajo tu cuenta.
     * En Uber Direct: Su `Customer ID` / `Organization ID` creado bajo tu cuenta.
   - De esta forma, en `admindelivery.html` solo se ingresa el Store ID / Customer ID
     de cada restaurante, o bien puedes usar tu API Maestra para dar de alta sucursales.

B) MODELO CON CUENTAS INDIVIDUALES (Si cada restaurante paga directamente a Rappi/Uber):
   - Cada restaurante se registra por su cuenta en Rappi/Uber, obtiene sus propios
     Client ID y Client Secret, y los ingresa en `admindelivery.html`.


3. ¿CÓMO FUNCIONA CON LA EDGE FUNCTION EN SUPABASE?
--------------------------------------------------------------------------------
1. Creaste la tabla SQL arriba.
2. Desplegaste la Edge Function `delivery-service` en Supabase.
3. Al guardar en `admindelivery.html`, los datos se guardan en la tabla SQL.
4. Cuando el cliente hace un pedido, la Edge Function lee la fila del restaurante
   desde la tabla `tragalero_delivery_config`, toma su Store ID / Customer ID,
   hace la llamada servidor-a-servidor a Rappi Cargo / Uber Direct y solicita el repartidor.
