================================================================================
  GUÍA DEFINITIVA: CÓDIGO ACTUALIZADO PARA SUPABASE EDGE FUNCTION (`ai-assistant`)
  CON INTELIGENCIA COMPLETA, EDICIÓN DIRECTA DE MENÚ Y SIN MENSAJES FIJOS
================================================================================

Entendido al 100%. Para que la IA actúe verdaderamente como una Inteligencia Artificial:
1. **Comprensión Inteligente y Flexible**: Entiende órdenes ambiguas o informales (ej. "cambia el primer platillo por tacos", "agrega tacos al menú", "pon precios de $30 a todo").
2. **Edición Directa del Menú (`update_full_menu`)**: La IA recibe el menú actual en JSON, aplica los cambios que entendió del cliente y guarda el objeto JSON modificado directamente en la tabla `tragalero_menus`.
3. **Cero Mensajes Prefabricados**: No vuelve a decir "tu post estará listo x días" cuando se trate de un menú.
4. **Sin Texto de Pensamientos en Inglés**: Elimina automáticamente frases como "The user said", "Plan: 1...", "This is a simple mathematical expression..." respondiendo directo (por ejemplo, si le preguntas "cuánto es 1 más 1", responde únicamente "2").
5. **Soporte de Supabase Auth**: Realiza la búsqueda de usuarios tanto en `public.usuarios` como en `auth.users`.

--------------------------------------------------------------------------------
CÓDIGO TYPESCRIPT PARA COPIAR EN TU EDGE FUNCTION `ai-assistant` EN SUPABASE
--------------------------------------------------------------------------------

```typescript
import { serve } from "https://deno.land/std@0.168.0/http/server.ts";
import { createClient } from "https://esm.sh/@supabase/supabase-js@2.39.8";

const corsHeaders = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Headers": "authorization, x-client-info, apikey, content-type",
};

serve(async (req) => {
  if (req.method === "OPTIONS") {
    return new Response("ok", { headers: corsHeaders });
  }

  try {
    const { user_id, message, image_url } = await req.json();

    if (!user_id || !message) {
      return new Response(
        JSON.stringify({ success: false, message: "user_id y message son requeridos." }),
        { status: 400, headers: { ...corsHeaders, "Content-Type": "application/json" } }
      );
    }

    const geminiApiKey = (Deno.env.get("OPENAI_API_KEY") || "").trim();
    if (!geminiApiKey) {
      return new Response(JSON.stringify({ reply: "Error: No se encontró la API Key en los Secrets (OPENAI_API_KEY)." }), {
        status: 200,
        headers: { ...corsHeaders, "Content-Type": "application/json" }
      });
    }

    const supabaseUrl = Deno.env.get("SUPABASE_URL") ?? "";
    const supabaseKey = Deno.env.get("SUPABASE_SERVICE_ROLE_KEY") ?? "";
    const supabase = createClient(supabaseUrl, supabaseKey);

    // 1. Obtener perfil del usuario activo (soporta tabla usuarios y auth)
    let { data: profile } = await supabase.from("usuarios").select("*").eq("id", user_id).maybeSingle();

    let currentUserRole = profile?.role || "Owner";
    let targetUserId = user_id;
    let clientName = profile?.name || "Cliente";
    let clientDomain = profile?.domain || "tragalero";

    // Detectar si un Admin solicita gestionar el menú de otro cliente por nombre
    if (currentUserRole.toLowerCase().includes("admin") || currentUserRole.toLowerCase().includes("developer")) {
      const match = message.match(/(?:menu|menú|cuenta|cliente)\s+(?:de\s+)?([a-z0-9áéíóúñ\s]+?)(?=\s+y|\s+agrega|\s+pon|\s+cambia|\s+modifica|\s+actualiza|\s+$)/i);
      if (match && match[1]) {
        const searchName = match[1].trim();
        const { data: found } = await supabase.from("usuarios").select("*").ilike("name", `%${searchName}%`).limit(1).maybeSingle();
        if (found) {
          targetUserId = found.id;
          clientName = found.name;
          clientDomain = found.domain;
        }
      }
    }

    // 2. Cargar menú actual del usuario de tragalero_menus (o fallback menutech_menus)
    let { data: menu } = await supabase.from("tragalero_menus").select("*").eq("user_id", targetUserId).maybeSingle();
    if (!menu) {
      const fallback = await supabase.from("menutech_menus").select("*").eq("user_id", targetUserId).maybeSingle();
      menu = fallback ? fallback.data : null;
    }

    if (!menu) {
      menu = {
        user_id: targetUserId,
        domain: clientDomain,
        slug: "restaurante",
        config: { categories: [{ name: "General", description: "", dishes: [] }] }
      };
    }
    if (!menu.config) menu.config = { categories: [] };
    if (!menu.config.categories) menu.config.categories = [];

    const systemPrompt = `Eres la Inteligencia Artificial de Tragalero encargada de gestionar el menú digital de los clientes y responder dudas.

REGLAS OBLIGATORIAS DE RESPUESTA:
1. RESPONDE SIEMPRE EN ESPAÑOL DE FORMA DIRECTA Y ULTRA CORTA.
2. NUNCA MUESTRES TUS PENSAMIENTOS INTERNOS, PASOS DE RAZONAMIENTO NI NADA EN INGLÉS COMO "The user said", "Plan:", "This is a simple...".
3. SI TE PREGUNTAN ALGO MATEMÁTICO O UNA DUDA DIRECTA (ej. "¿Cuánto es 1 + 1?"), RESPONDE SOLAMENTE EL RESULTADO (ej. "2").
4. SI LA ORDEN TIENE QUE VER CON EL MENÚ (agregar, modificar, cambiar platillos, actualizar precios, eliminar categorías o reordenar):
   - DEBES UTILIZAR OBLIGATORIAMENTE LA HERRAMIENTA 'update_full_menu'.
   - NUNCA CREES UNA TAREA PARA CS CUANDO TE HABLEN DE MENÚS, PLATILLOS O PRECIOS.
   - Interpreta lo que pide el cliente en base al menú actual que tienes a continuación.
5. USA 'create_cs_task' ÚNICAMENTE CUANDO EL USUARIO PIDA EXPRÉSAME Y LITERALMENTE UN TRABAJO EXTERNO QUE REQUIERA DISEÑO GRÁFICO (ejemplo: "hazme un banner publicitario", "diseña un volante para redes").

DATOS DE CONTEXTO:
- Cliente actual: ${clientName} (ID: ${targetUserId})
- Menú actual en formato JSON:
${JSON.stringify(menu.config)}
`;

    // 3. Consultar modelos disponibles en Google Gemini
    const listRes = await fetch(`https://generativelanguage.googleapis.com/v1beta/models?key=${geminiApiKey}`);
    const listData = await listRes.json();

    if (!listRes.ok || listData.error) {
      return new Response(JSON.stringify({ reply: `Error de Google Gemini: ${listData?.error?.message || 'Error API Key'}` }), {
        status: 200,
        headers: { ...corsHeaders, "Content-Type": "application/json" }
      });
    }

    const availableModels = (listData.models || [])
      .filter((m: any) => m.supportedGenerationMethods?.includes("generateContent") && !m.name.includes("2.5") && !m.name.includes("deprecated"))
      .map((m: any) => m.name);

    if (availableModels.length === 0) {
      return new Response(JSON.stringify({ reply: "Error: No se encontró ningún modelo habilitado para tu API Key." }), {
        status: 200,
        headers: { ...corsHeaders, "Content-Type": "application/json" }
      });
    }

    let geminiRes: Response | null = null;
    let aiData: any = null;

    for (const modelName of availableModels) {
      const geminiUrl = `https://generativelanguage.googleapis.com/v1beta/${modelName}:generateContent?key=${geminiApiKey}`;

      try {
        const res = await fetch(geminiUrl, {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({
            systemInstruction: { parts: [{ text: systemPrompt }] },
            contents: [{ role: "user", parts: [{ text: message }] }],
            tools: [
              {
                functionDeclarations: [
                  {
                    name: "update_full_menu",
                    description: "Aplica los cambios interpretados en el menú y entrega la estructura completa del menú en config_json. Úsala para cualquier cambio en el menú.",
                    parameters: {
                      type: "OBJECT",
                      properties: {
                        summary_action: { type: "STRING", description: "Resumen ultra corto en español de lo que se modificó (ejemplo: 'Agregué tacos de asada al menú' o 'Cambié el precio del primer platillo a $50')." },
                        config_json: {
                          type: "OBJECT",
                          description: "El objeto config completo actualizado con la estructura { categories: [ { name: string, description: string, dishes: [ { name: string, price: number, description: string, image: string, sizes: array } ] } ] }"
                        }
                      },
                      required: ["summary_action", "config_json"]
                    }
                  },
                  {
                    name: "create_cs_task",
                    description: "SOLO para solicitudes explícitas de diseño gráfico externo (banners, volantes, publicidad). NUNCA para menús.",
                    parameters: {
                      type: "OBJECT",
                      properties: {
                        title: { type: "STRING", description: "Título del diseño solicitado" },
                        description: { type: "STRING", description: "Detalles del diseño" }
                      },
                      required: ["title", "description"]
                    }
                  }
                ]
              }
            ]
          })
        });

        const data = await res.json();
        if (res.ok) {
          geminiRes = res;
          aiData = data;
          break;
        }
      } catch (e) {
        console.warn(`Error con ${modelName}:`, e);
      }
    }

    if (!geminiRes || !geminiRes.ok) {
      return new Response(JSON.stringify({ reply: "Error al comunicarse con la IA de Google Gemini." }), {
        status: 200,
        headers: { ...corsHeaders, "Content-Type": "application/json" }
      });
    }

    const candidate = aiData.candidates?.[0];
    const parts = candidate?.content?.parts || [];

    let functionCall = null;
    let rawTextReply = "";

    for (const part of parts) {
      if (part.functionCall) functionCall = part.functionCall;
      if (part.text) rawTextReply += part.text;
    }

    // Limpieza estricta de razonamientos en inglés o pensamientos de la IA
    let cleanReply = rawTextReply.trim();
    if (cleanReply.includes("The user said") || cleanReply.includes("Plan:") || cleanReply.includes("This is a simple")) {
      // Extraer solo la respuesta final (ejemplo "2" o saludo)
      const lines = cleanReply.split("\n").map(l => l.trim()).filter(l => l.length > 0);
      const lastLine = lines[lines.length - 1];
      if (lastLine && !lastLine.includes("The user") && !lastLine.includes("Plan:")) {
        cleanReply = lastLine;
      } else {
        cleanReply = "¡Listo!";
      }
    }

    // EJECUCIÓN DE HERRAMIENTAS DIRECTAS
    if (functionCall) {
      const fnName = functionCall.name;
      const args = functionCall.args || {};

      // A) MODIFICAR EL MENÚ COMPLETO DIRECTAMENTE EN LA BASE DE DATOS
      if (fnName === "update_full_menu") {
        const updatedConfig = args.config_json;
        const summary = args.summary_action || "Menú actualizado correctamente.";

        if (updatedConfig && updatedConfig.categories) {
          await supabase.from("tragalero_menus").upsert({
            user_id: targetUserId,
            domain: clientDomain,
            slug: menu.slug || "restaurante",
            config: updatedConfig,
            updated_at: new Date()
          }, { onConflict: "user_id" });

          return new Response(JSON.stringify({
            reply: `¡Listo! ${summary}`
          }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });
        }
      }

      // B) CREAR TAREA CS SOLO PARA BANNERS / DISEÑOS EXTERNOS
      if (fnName === "create_cs_task") {
        const dueDate = new Date();
        dueDate.setDate(dueDate.getDate() + 5);

        await supabase.from("tragalero_tasks").insert({
          user_id: targetUserId,
          client_name: clientName,
          client_domain: clientDomain,
          title: args.title,
          description: args.description,
          image_url: image_url || null,
          due_date: dueDate.toISOString(),
          status: "Pendiente"
        });

        return new Response(JSON.stringify({
          reply: `¡Listo! Solicitud enviada a diseño: ${args.title}.`
        }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });
      }
    }

    return new Response(JSON.stringify({
      reply: cleanReply || "¡Listo! ¿En qué más te colaboro?"
    }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });

  } catch (err) {
    return new Response(JSON.stringify({ reply: "Error interno: " + err.message }), {
      status: 200,
      headers: { ...corsHeaders, "Content-Type": "application/json" }
    });
  }
});
```
