  GUÍA SENCILLA: INTEGRACIÓN DEL CHATBOT DE IA CON GOOGLE GEMINI Y TAREAS (CS)
  PARA TRAGALERO
================================================================================

¡Hola! Esta guía está explicada paso a paso para que entiendas exactamente cómo
funciona tu Chatbot con Inteligencia Artificial, cómo modifica menús directamente
en la base de datos (agregar categorías, agregar platillos, modificar precios,
eliminar platillos) y cómo asigna solicitudes externas (banners, posts, diseños)
al equipo de Atención a Clientes (CS) en `tragalero_tasks`.

--------------------------------------------------------------------------------
1. ¿CÓMO FUNCIONA EL CHATBOT CON IA EN TU PLATAFORMA?
--------------------------------------------------------------------------------
1. **Atención Inteligente**: Cuando un usuario (Cliente o Administrador) escribe
   o habla por el micrófono, el asistente entiende el contexto:
   - Si eres **Admin** y pides: *"Entra al menú de Antonio y agrega una categoría Tacos con tacos de asada $20, tripa $35 y pastor $40"*, la IA busca el cliente Antonio, entra a su menú y realiza las modificaciones directamente en la base de datos.
   - Si eres un **Cliente regular**, modifica directamente el menú de tu cuenta.
   - Si la solicitud es un **servicio externo** (banners, diseño, redes sociales, soporte web): la IA crea una tarea en `tragalero_tasks` con fecha límite de 5 días y confirma al usuario en lenguaje natural.

2. **Acción Directa en la Base de Datos**:
   - Agrega categorías nuevas.
   - Agrega platillos con sus precios.
   - Actualiza precios o nombres de platillos existentes.
   - Elimina platillos o categorías solicitadas.


--------------------------------------------------------------------------------
2. CÓDIGO TYPESCRIPT COMPLETO PARA SUPABASE EDGE FUNCTION (`ai-assistant`)
--------------------------------------------------------------------------------

Copia y pega este código en tu Edge Function `ai-assistant` en Supabase:

```typescript
import { serve } from "https://deno.land/std@0.168.0/http/server.ts";
import { createClient } from "https://esm.sh/@supabase/supabase-js@2.39.8";

const corsHeaders = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Headers": "authorization, x-client-info, apikey, content-type",
};

serve(async (req) => {
  if (req.method === "OPTIONS") {
    return new Response("ok", { headers: corsHeaders });
  }

  try {
    const { user_id, message, image_url } = await req.json();

    if (!user_id || !message) {
      return new Response(
        JSON.stringify({ success: false, message: "user_id y message son requeridos." }),
        { status: 400, headers: { ...corsHeaders, "Content-Type": "application/json" } }
      );
    }

    const geminiApiKey = (Deno.env.get("OPENAI_API_KEY") || "").trim();
    if (!geminiApiKey) {
      return new Response(JSON.stringify({ reply: "Error: No se encontró la API Key (OPENAI_API_KEY) en los Secrets de Supabase." }), {
        status: 200,
        headers: { ...corsHeaders, "Content-Type": "application/json" }
      });
    }

    const supabaseUrl = Deno.env.get("SUPABASE_URL") ?? "";
    const supabaseKey = Deno.env.get("SUPABASE_SERVICE_ROLE_KEY") ?? "";
    const supabase = createClient(supabaseUrl, supabaseKey);

    // Obtener datos del usuario activo
    const { data: profile } = await supabase.from("usuarios").select("*").eq("id", user_id).single();
    const currentUserRole = profile?.role || "Owner";
    let targetUserId = user_id;
    let clientName = profile?.name || "Cliente";
    let clientDomain = profile?.domain || "tragalero";

    // Si es admin, permite buscar otros clientes si lo especifica en el mensaje
    let menuUser = profile;
    if (currentUserRole.toLowerCase().includes("admin") || currentUserRole.toLowerCase().includes("developer")) {
      const match = message.match(/(?:menu|menú|cuenta|cliente)\s+(?:de\s+)?([a-z0-9áéíóúñ\s]+?)(?=\s+y|\s+agrega|\s+pon|\s+cambia|\s+modifica|\s+$)/i);
      if (match && match[1]) {
        const searchName = match[1].trim();
        const { data: found } = await supabase.from("usuarios").select("*").ilike("name", `%${searchName}%`).limit(1).maybeSingle();
        if (found) {
          targetUserId = found.id;
          clientName = found.name;
          clientDomain = found.domain;
          menuUser = found;
        }
      }
    }

    // Cargar menú del usuario destino
    let { data: menu } = await supabase.from("tragalero_menus").select("*").eq("user_id", targetUserId).maybeSingle();
    if (!menu) {
      const fallback = await supabase.from("menutech_menus").select("*").eq("user_id", targetUserId).maybeSingle();
      menu = fallback ? fallback.data : null;
    }

    if (!menu) {
      menu = {
        user_id: targetUserId,
        domain: clientDomain,
        slug: "restaurante",
        config: { categories: [{ name: "General", dishes: [] }] }
      };
    }
    if (!menu.config) menu.config = { categories: [] };
    if (!menu.config.categories) menu.config.categories = [];

    const systemPrompt = `Eres el asistente inteligente de administración de Tragalero.
REGLA OBLIGATORIA: RESPONDE SIEMPRE DIRECTAMENTE AL USUARIO EN ESPAÑOL. NUNCA INCLUYAS TUS PENSAMIENTOS INTERNOS, PLANES, PASOS DE RAZONAMIENTO NI "The user said..." EN LA RESPUESTA.
Usuario actual: ${profile?.name || "Usuario"} (Rol: ${currentUserRole}).
Cliente gestionado actualmente: ${clientName} (ID: ${targetUserId}).
Menú actual de ${clientName}: ${JSON.stringify(menu.config)}

Instrucciones:
1. Si el usuario pide agregar una categoría nueva o platillos al menú, usa 'add_menu_item' o 'add_category'.
2. Si pide cambiar precios o datos de platillos existentes, usa 'update_dish_price'.
3. Si pide eliminar un platillo o categoría, usa 'delete_menu_item'.
4. Si pide algo externo (diseños, banners, publicaciones de Facebook, cambios web complejos que requieren trabajo manual del equipo de CS), usa 'create_cs_task'.`;

    // 1. Obtener lista de modelos de Google ignorando modelos no disponibles
    const listRes = await fetch(`https://generativelanguage.googleapis.com/v1beta/models?key=${geminiApiKey}`);
    const listData = await listRes.json();

    if (!listRes.ok || listData.error) {
      const gError = listData?.error?.message || "Error al autenticar con Google Gemini.";
      return new Response(JSON.stringify({ reply: `Error de Google Gemini: ${gError}` }), {
        status: 200,
        headers: { ...corsHeaders, "Content-Type": "application/json" }
      });
    }

    const availableModels = listData.models || [];
    const targetModelObj = availableModels.find((m: any) =>
      m.supportedGenerationMethods?.includes("generateContent") &&
      !m.name.includes("2.5") && !m.name.includes("deprecated") &&
      (m.name.includes("flash") || m.name.includes("gemini"))
    ) || availableModels.find((m: any) => m.supportedGenerationMethods?.includes("generateContent") && !m.name.includes("2.5"));

    if (!targetModelObj || !targetModelObj.name) {
      return new Response(JSON.stringify({ reply: "Error: No se encontró ningún modelo de Gemini válido habilitado para tu API key." }), {
        status: 200,
        headers: { ...corsHeaders, "Content-Type": "application/json" }
      });
    }

    const modelName = targetModelObj.name;
    const geminiUrl = `https://generativelanguage.googleapis.com/v1beta/${modelName}:generateContent?key=${geminiApiKey}`;

    const geminiRes = await fetch(geminiUrl, {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({
        systemInstruction: { parts: [{ text: systemPrompt }] },
        contents: [{ role: "user", parts: [{ text: message }] }],
        tools: [
          {
            functionDeclarations: [
              {
                name: "add_category",
                description: "Agrega una nueva categoría al menú del restaurante.",
                parameters: {
                  type: "OBJECT",
                  properties: {
                    category_name: { type: "STRING", description: "Nombre de la categoría" }
                  },
                  required: ["category_name"]
                }
              },
              {
                name: "add_menu_item",
                description: "Agrega platillos (uno o varios) a una categoría del menú.",
                parameters: {
                  type: "OBJECT",
                  properties: {
                    category_name: { type: "STRING", description: "Nombre de la categoría donde colocar los platillos" },
                    dishes: {
                      type: "ARRAY",
                      description: "Lista de platillos a agregar",
                      items: {
                        type: "OBJECT",
                        properties: {
                          name: { type: "STRING", description: "Nombre del platillo" },
                          price: { type: "NUMBER", description: "Precio en pesos MXN" },
                          description: { type: "STRING", description: "Descripción opcional" }
                        },
                        required: ["name", "price"]
                      }
                    }
                  },
                  required: ["category_name", "dishes"]
                }
              },
              {
                name: "update_dish_price",
                description: "Cambia el precio de un platillo existente en el menú.",
                parameters: {
                  type: "OBJECT",
                  properties: {
                    dish_name: { type: "STRING", description: "Nombre exacto o aproximado del platillo" },
                    new_price: { type: "NUMBER", description: "Nuevo precio en pesos MXN" }
                  },
                  required: ["dish_name", "new_price"]
                }
              },
              {
                name: "delete_menu_item",
                description: "Elimina un platillo o una categoría del menú.",
                parameters: {
                  type: "OBJECT",
                  properties: {
                    item_name: { type: "STRING", description: "Nombre del platillo o categoría a eliminar" },
                    type: { type: "STRING", description: "'dish' o 'category'" }
                  },
                  required: ["item_name", "type"]
                }
              },
              {
                name: "create_cs_task",
                description: "Crea una tarea para el equipo de CS cuando se solicita algo externo (banner, diseño, publicación, soporte web).",
                parameters: {
                  type: "OBJECT",
                  properties: {
                    title: { type: "STRING", description: "Título breve de la tarea" },
                    description: { type: "STRING", description: "Detalles completos de la solicitud" }
                  },
                  required: ["title", "description"]
                }
              }
            ]
          }
        ]
      })
    });

    const aiData = await geminiRes.json();

    if (!geminiRes.ok) {
      const errorMsg = aiData?.error?.message || JSON.stringify(aiData?.error) || "Error al generar contenido.";
      return new Response(JSON.stringify({ reply: `Error en Gemini API (${modelName}): ${errorMsg}` }), {
        status: 200,
        headers: { ...corsHeaders, "Content-Type": "application/json" }
      });
    }

    const candidate = aiData.candidates?.[0];
    const parts = candidate?.content?.parts || [];

    let functionCall = null;
    let textReply = "";

    for (const part of parts) {
      if (part.functionCall) {
        functionCall = part.functionCall;
      }
      if (part.text) {
        textReply += part.text;
      }
    }

    // Limpiar si vino pensamiento interno
    if (textReply.includes("Plan:") || textReply.includes("The user said")) {
      textReply = textReply.split(/¡|Hola|¿|Entendido/i).slice(1).join("¡");
      if (textReply) textReply = "¡" + textReply;
    }

    if (functionCall) {
      const fnName = functionCall.name;
      const args = functionCall.args || {};

      // A) AGREGAR CATEGORÍA
      if (fnName === "add_category") {
        const catName = args.category_name.charAt(0).toUpperCase() + args.category_name.slice(1);
        let existingCat = menu.config.categories.find((c: any) => c.name.toLowerCase() === catName.toLowerCase());
        if (!existingCat) {
          menu.config.categories.push({ name: catName, description: "", dishes: [] });
          await supabase.from("tragalero_menus").upsert({
            user_id: targetUserId,
            domain: clientDomain,
            slug: menu.slug || "restaurante",
            config: menu.config,
            updated_at: new Date()
          }, { onConflict: "user_id" });
        }
        return new Response(JSON.stringify({
          reply: `¡Listo! He agregado la categoría "${catName}" al menú de ${clientName}.`
        }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });
      }

      // B) AGREGAR PLATILLOS
      if (fnName === "add_menu_item") {
        const catNameInput = args.category_name || "General";
        let targetCat = menu.config.categories.find((c: any) => c.name.toLowerCase().includes(catNameInput.toLowerCase()));

        if (!targetCat) {
          const formattedCatName = catNameInput.charAt(0).toUpperCase() + catNameInput.slice(1);
          targetCat = { name: formattedCatName, description: "", dishes: [] };
          menu.config.categories.push(targetCat);
        }
        if (!targetCat.dishes) targetCat.dishes = [];

        const addedNames: string[] = [];
        (args.dishes || []).forEach((d: any) => {
          const dName = d.name.charAt(0).toUpperCase() + d.name.slice(1);
          targetCat.dishes.push({
            name: dName,
            description: d.description || "",
            price: d.price || 0,
            image: "",
            sizes: []
          });
          addedNames.push(`${dName} ($${d.price})`);
        });

        await supabase.from("tragalero_menus").upsert({
          user_id: targetUserId,
          domain: clientDomain,
          slug: menu.slug || "restaurante",
          config: menu.config,
          updated_at: new Date()
        }, { onConflict: "user_id" });

        return new Response(JSON.stringify({
          reply: `¡Listo! He agregado a la categoría "${targetCat.name}" los platillos: ${addedNames.join(", ")} en el menú de ${clientName}.`
        }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });
      }

      // C) ACTUALIZAR PRECIO
      if (fnName === "update_dish_price") {
        let updated = false;
        let foundDishName = args.dish_name;
        menu.config.categories.forEach((cat: any) => {
          (cat.dishes || []).forEach((dish: any) => {
            if (dish.name.toLowerCase().includes(args.dish_name.toLowerCase())) {
              dish.price = args.new_price;
              foundDishName = dish.name;
              updated = true;
            }
          });
        });

        if (updated) {
          await supabase.from("tragalero_menus").upsert({
            user_id: targetUserId,
            domain: clientDomain,
            slug: menu.slug || "restaurante",
            config: menu.config,
            updated_at: new Date()
          }, { onConflict: "user_id" });

          return new Response(JSON.stringify({
            reply: `¡Listo! He actualizado el precio del platillo "${foundDishName}" a $${args.new_price} MXN en el menú de ${clientName}.`
          }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });
        } else {
          return new Response(JSON.stringify({
            reply: `No pude encontrar el platillo "${args.dish_name}" en el menú de ${clientName}.`
          }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });
        }
      }

      // D) ELIMINAR PLATILLO O CATEGORÍA
      if (fnName === "delete_menu_item") {
        const itemName = args.item_name.toLowerCase();
        let deleted = false;

        if (args.type === "category") {
          const initialLen = menu.config.categories.length;
          menu.config.categories = menu.config.categories.filter((c: any) => !c.name.toLowerCase().includes(itemName));
          if (menu.config.categories.length < initialLen) deleted = true;
        } else {
          menu.config.categories.forEach((cat: any) => {
            if (cat.dishes) {
              const initDLen = cat.dishes.length;
              cat.dishes = cat.dishes.filter((d: any) => !d.name.toLowerCase().includes(itemName));
              if (cat.dishes.length < initDLen) deleted = true;
            }
          });
        }

        if (deleted) {
          await supabase.from("tragalero_menus").upsert({
            user_id: targetUserId,
            domain: clientDomain,
            slug: menu.slug || "restaurante",
            config: menu.config,
            updated_at: new Date()
          }, { onConflict: "user_id" });

          return new Response(JSON.stringify({
            reply: `¡Listo! He eliminado "${args.item_name}" del menú de ${clientName}.`
          }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });
        } else {
          return new Response(JSON.stringify({
            reply: `No encontré "${args.item_name}" para eliminar en el menú de ${clientName}.`
          }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });
        }
      }

      // E) CREAR TAREA PARA ATENCIÓN A CLIENTES (CS)
      if (fnName === "create_cs_task") {
        const dueDate = new Date();
        dueDate.setDate(dueDate.getDate() + 5);

        await supabase.from("tragalero_tasks").insert({
          user_id: targetUserId,
          client_name: clientName,
          client_domain: clientDomain,
          title: args.title,
          description: args.description,
          image_url: image_url || null,
          due_date: dueDate.toISOString(),
          status: "Pendiente"
        });

        const formattedDate = dueDate.toLocaleDateString("es-MX", { day: "numeric", month: "long", year: "numeric" });
        return new Response(JSON.stringify({
          reply: `¡Listo! He registrado la solicitud "${args.title}" para ${clientName}. El equipo de atención a clientes la resolverá antes del ${formattedDate}.`
        }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });
      }
    }

    return new Response(JSON.stringify({
      reply: textReply || "Entendido. ¿En qué más te puedo colaborar hoy?"
    }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });

  } catch (err) {
    return new Response(JSON.stringify({ reply: "Error interno en Edge Function: " + err.message }), {
      status: 200,
      headers: { ...corsHeaders, "Content-Type": "application/json" }
    });
  }
});
```
