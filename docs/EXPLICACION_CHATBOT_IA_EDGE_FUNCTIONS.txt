================================================================================
  GUÍA SENCILLA: INTEGRACIÓN DEL CHATBOT DE IA CON GOOGLE GEMINI Y TAREAS (CS)
  PARA TRAGALERO
================================================================================

¡Hola! Esta guía está explicada paso a paso para que entiendas exactamente cómo
funciona tu Chatbot con Inteligencia Artificial, cómo modifica menús directamente
en la base de datos (agregar categorías, agregar platillos, modificar precios,
eliminar platillos) y cómo asigna solicitudes externas (banners, posts, diseños)
al equipo de Atención a Clientes (CS) en `tragalero_tasks`.

--------------------------------------------------------------------------------
1. ¿CÓMO FUNCIONA EL CHATBOT CON IA EN TU PLATAFORMA?
--------------------------------------------------------------------------------
1. **Atención Inteligente Corta y Directa**:
   - Saludos breves sin textos de pensamientos internos ("The user said...", "Plan:...").
   - Si eres **Admin** y pides: *"Entra al menú de Antonio y agrega una categoría Tacos con tacos de asada $20, tripa $35 y pastor $40"*, la IA busca el cliente Antonio, entra a su menú y realiza las modificaciones directamente en la base de datos `tragalero_menus`.
   - Si la orden es un **servicio externo** (diseño de banner, cambio complejo de plantilla web, redes sociales): crea una tarea en `tragalero_tasks` para CS sin usar frases fijas de "post".

2. **Acción Directa en la Base de Datos**:
   - Agrega categorías nuevas.
   - Agrega platillos con sus precios.
   - Actualiza precios o nombres de platillos existentes.
   - Elimina platillos o categorías solicitadas.


--------------------------------------------------------------------------------
2. CÓDIGO TYPESCRIPT COMPLETO PARA SUPABASE EDGE FUNCTION (`ai-assistant`)
--------------------------------------------------------------------------------

Copia y pega este código en tu Edge Function `ai-assistant` en Supabase:

```typescript
import { serve } from "https://deno.land/std@0.168.0/http/server.ts";
import { createClient } from "https://esm.sh/@supabase/supabase-js@2.39.8";

const corsHeaders = {
  "Access-Control-Allow-Origin": "*",
  "Access-Control-Allow-Headers": "authorization, x-client-info, apikey, content-type",
};

serve(async (req) => {
  if (req.method === "OPTIONS") {
    return new Response("ok", { headers: corsHeaders });
  }

  try {
    const { user_id, message, image_url } = await req.json();

    if (!user_id || !message) {
      return new Response(
        JSON.stringify({ success: false, message: "user_id y message son requeridos." }),
        { status: 400, headers: { ...corsHeaders, "Content-Type": "application/json" } }
      );
    }

    const geminiApiKey = (Deno.env.get("OPENAI_API_KEY") || "").trim();
    if (!geminiApiKey) {
      return new Response(JSON.stringify({ reply: "Error: No se encontró la API Key (OPENAI_API_KEY) en los Secrets de Supabase." }), {
        status: 200,
        headers: { ...corsHeaders, "Content-Type": "application/json" }
      });
    }

    const supabaseUrl = Deno.env.get("SUPABASE_URL") ?? "";
    const supabaseKey = Deno.env.get("SUPABASE_SERVICE_ROLE_KEY") ?? "";
    const supabase = createClient(supabaseUrl, supabaseKey);

    // Obtener datos del usuario activo
    const { data: profile } = await supabase.from("usuarios").select("*").eq("id", user_id).single();
    const currentUserRole = profile?.role || "Owner";
    let targetUserId = user_id;
    let clientName = profile?.name || "Cliente";
    let clientDomain = profile?.domain || "tragalero";

    // Detectar si un Administrador solicita gestionar la cuenta de otro cliente
    if (currentUserRole.toLowerCase().includes("admin") || currentUserRole.toLowerCase().includes("developer")) {
      const match = message.match(/(?:menu|menú|cuenta|cliente)\s+(?:de\s+)?([a-z0-9áéíóúñ\s]+?)(?=\s+y|\s+agrega|\s+pon|\s+cambia|\s+modifica|\s+actualiza|\s+$)/i);
      if (match && match[1]) {
        const searchName = match[1].trim();
        const { data: found } = await supabase.from("usuarios").select("*").ilike("name", `%${searchName}%`).limit(1).maybeSingle();
        if (found) {
          targetUserId = found.id;
          clientName = found.name;
          clientDomain = found.domain;
        }
      }
    }

    // Cargar menú del usuario destino
    let { data: menu } = await supabase.from("tragalero_menus").select("*").eq("user_id", targetUserId).maybeSingle();
    if (!menu) {
      const fallback = await supabase.from("menutech_menus").select("*").eq("user_id", targetUserId).maybeSingle();
      menu = fallback ? fallback.data : null;
    }

    if (!menu) {
      menu = {
        user_id: targetUserId,
        domain: clientDomain,
        slug: "restaurante",
        config: { categories: [{ name: "General", dishes: [] }] }
      };
    }
    if (!menu.config) menu.config = { categories: [] };
    if (!menu.config.categories) menu.config.categories = [];

    const systemPrompt = `Eres el asistente inteligente de administración de Tragalero.
REGLA NÚMERO 1 Y ABSOLUTA: RESPONDE SIEMPRE EN ESPAÑOL Y DE FORMA CORTA Y DIRECTA.
NUNCA INCLUYAS TUS PENSAMIENTOS INTERNOS, PASOS DE RAZONAMIENTO, "The user said", "Plan:" NI NADA EN INGLÉS EN TU RESPUESTA.
Si el usuario dice "Hola", responde únicamente: "¡Hola! ¿En qué te puedo colaborar hoy?"

Usuario actual: ${profile?.name || "Usuario"} (Rol: ${currentUserRole}).
Cliente gestionado actualmente: ${clientName} (ID: ${targetUserId}).
Menú actual de ${clientName}: ${JSON.stringify(menu.config)}

Instrucciones de herramientas:
1. SIEMPRE QUE EL USUARIO PIDA AGREGAR CATEGORÍAS, AGREGAR PLATILLOS, CAMBIAR PRECIOS O ELIMINAR ELEMENTOS DEL MENÚ: USA 'manage_menu'. OBLIGATORIO: NO USES 'create_cs_task' PARA CAMBIOS DE MENÚ.
2. USA 'create_cs_task' ÚNICAMENTE PARA TRABAJOS EXTERNOS (diseños de banners, publicaciones de redes sociales, desarrollo web complejo o soporte asistido manual).`;

    // 1. Obtener lista de modelos de Google ignorando modelos no disponibles
    const listRes = await fetch(`https://generativelanguage.googleapis.com/v1beta/models?key=${geminiApiKey}`);
    const listData = await listRes.json();

    if (!listRes.ok || listData.error) {
      const gError = listData?.error?.message || "Error al autenticar con Google Gemini.";
      return new Response(JSON.stringify({ reply: `Error de Google Gemini: ${gError}` }), {
        status: 200,
        headers: { ...corsHeaders, "Content-Type": "application/json" }
      });
    }

    const availableModels = (listData.models || [])
      .filter((m: any) => m.supportedGenerationMethods?.includes("generateContent") && !m.name.includes("2.5") && !m.name.includes("deprecated"))
      .map((m: any) => m.name);

    if (availableModels.length === 0) {
      return new Response(JSON.stringify({ reply: "Error: No se encontró ningún modelo de Gemini válido habilitado para tu API key." }), {
        status: 200,
        headers: { ...corsHeaders, "Content-Type": "application/json" }
      });
    }

    let geminiRes: Response | null = null;
    let aiData: any = null;
    let lastUsedModel = "";

    for (const modelName of availableModels) {
      lastUsedModel = modelName;
      const geminiUrl = `https://generativelanguage.googleapis.com/v1beta/${modelName}:generateContent?key=${geminiApiKey}`;

      try {
        const res = await fetch(geminiUrl, {
          method: "POST",
          headers: { "Content-Type": "application/json" },
          body: JSON.stringify({
            systemInstruction: { parts: [{ text: systemPrompt }] },
            contents: [{ role: "user", parts: [{ text: message }] }],
            tools: [
              {
                functionDeclarations: [
                  {
                    name: "manage_menu",
                    description: "Modifica directamente la base de datos del menú: agrega categorías, agrega platillos con sus precios, actualiza precios o elimina elementos.",
                    parameters: {
                      type: "OBJECT",
                      properties: {
                        action: { type: "STRING", description: "'add' (para agregar categorías/platillos), 'update' (para cambiar precios), 'delete' (para borrar)" },
                        category_name: { type: "STRING", description: "Nombre de la categoría afectada o a crear" },
                        dishes: {
                          type: "ARRAY",
                          description: "Platillos a agregar o actualizar",
                          items: {
                            type: "OBJECT",
                            properties: {
                              name: { type: "STRING", description: "Nombre del platillo" },
                              price: { type: "NUMBER", description: "Precio en pesos MXN" },
                              description: { type: "STRING", description: "Descripción opcional" }
                            },
                            required: ["name", "price"]
                          }
                        },
                        delete_item_name: { type: "STRING", description: "Nombre del platillo o categoría a eliminar si la acción es 'delete'" }
                      },
                      required: ["action"]
                    }
                  },
                  {
                    name: "create_cs_task",
                    description: "Crea una tarea para el equipo de CS sólo cuando se solicita un trabajo externo (banner, diseño, redes sociales).",
                    parameters: {
                      type: "OBJECT",
                      properties: {
                        title: { type: "STRING", description: "Título descriptivo del servicio solicitado" },
                        description: { type: "STRING", description: "Detalles completos" }
                      },
                      required: ["title", "description"]
                    }
                  }
                ]
              }
            ]
          })
        });

        const data = await res.json();
        if (res.ok) {
          geminiRes = res;
          aiData = data;
          break;
        } else if (res.status === 429 || res.status === 503) {
          aiData = data;
          continue;
        } else {
          aiData = data;
          break;
        }
      } catch (e) {
        console.warn(`Error al conectar con ${modelName}:`, e);
      }
    }

    if (!geminiRes || !geminiRes.ok) {
      const errorMsg = aiData?.error?.message || JSON.stringify(aiData?.error) || "Error al generar contenido.";
      return new Response(JSON.stringify({ reply: `Error en Gemini API (${lastUsedModel}): ${errorMsg}` }), {
        status: 200,
        headers: { ...corsHeaders, "Content-Type": "application/json" }
      });
    }

    const candidate = aiData.candidates?.[0];
    const parts = candidate?.content?.parts || [];

    let functionCall = null;
    let textReply = "";

    for (const part of parts) {
      if (part.functionCall) {
        functionCall = part.functionCall;
      }
      if (part.text) {
        textReply += part.text;
      }
    }

    // Limpiar pensamientos internos o razonamientos si la IA los incluyó
    if (textReply.includes("The user said") || textReply.includes("Plan:") || textReply.includes("I should")) {
      const matchGreeting = textReply.match(/(¡Hola[^!.]*!|\bHola\b[^!.]*|\b¿En qué[^?]*\?)/i);
      if (matchGreeting) {
        textReply = matchGreeting[0];
      } else {
        textReply = "¡Hola! ¿En qué te puedo colaborar hoy?";
      }
    }

    if (functionCall) {
      const fnName = functionCall.name;
      const args = functionCall.args || {};

      // A) GESTIONAR MENÚ DIRECTO
      if (fnName === "manage_menu") {
        const action = args.action || "add";
        let catName = args.category_name || "General";
        catName = catName.charAt(0).toUpperCase() + catName.slice(1);

        let targetCat = menu.config.categories.find((c: any) => c.name.toLowerCase().includes(catName.toLowerCase()));

        if (action === "add") {
          if (!targetCat) {
            targetCat = { name: catName, description: "", dishes: [] };
            menu.config.categories.push(targetCat);
          }
          if (!targetCat.dishes) targetCat.dishes = [];

          const addedList: string[] = [];
          (args.dishes || []).forEach((d: any) => {
            const dName = d.name.charAt(0).toUpperCase() + d.name.slice(1);
            // Evitar duplicados exactos
            let existingDish = targetCat.dishes.find((item: any) => item.name.toLowerCase() === dName.toLowerCase());
            if (existingDish) {
              existingDish.price = d.price;
            } else {
              targetCat.dishes.push({
                name: dName,
                description: d.description || "",
                price: d.price || 0,
                image: "",
                sizes: []
              });
            }
            addedList.push(`${dName} ($${d.price})`);
          });

          await supabase.from("tragalero_menus").upsert({
            user_id: targetUserId,
            domain: clientDomain,
            slug: menu.slug || "restaurante",
            config: menu.config,
            updated_at: new Date()
          }, { onConflict: "user_id" });

          const details = addedList.length > 0 ? `: ${addedList.join(", ")}` : "";
          return new Response(JSON.stringify({
            reply: `¡Listo! He actualizado el menú de ${clientName} agregando la categoría "${targetCat.name}"${details}.`
          }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });
        }

        if (action === "update") {
          let updated = false;
          let detailsList: string[] = [];
          (args.dishes || []).forEach((d: any) => {
            menu.config.categories.forEach((cat: any) => {
              (cat.dishes || []).forEach((dish: any) => {
                if (dish.name.toLowerCase().includes(d.name.toLowerCase())) {
                  dish.price = d.price;
                  updated = true;
                  detailsList.push(`${dish.name} a $${d.price}`);
                }
              });
            });
          });

          if (updated) {
            await supabase.from("tragalero_menus").upsert({
              user_id: targetUserId,
              domain: clientDomain,
              slug: menu.slug || "restaurante",
              config: menu.config,
              updated_at: new Date()
            }, { onConflict: "user_id" });

            return new Response(JSON.stringify({
              reply: `¡Listo! He actualizado en el menú de ${clientName}: ${detailsList.join(", ")}.`
            }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });
          }
        }

        if (action === "delete") {
          const itemToDelete = (args.delete_item_name || "").toLowerCase();
          menu.config.categories = menu.config.categories.filter((c: any) => !c.name.toLowerCase().includes(itemToDelete));
          menu.config.categories.forEach((cat: any) => {
            if (cat.dishes) {
              cat.dishes = cat.dishes.filter((d: any) => !d.name.toLowerCase().includes(itemToDelete));
            }
          });

          await supabase.from("tragalero_menus").upsert({
            user_id: targetUserId,
            domain: clientDomain,
            slug: menu.slug || "restaurante",
            config: menu.config,
            updated_at: new Date()
          }, { onConflict: "user_id" });

          return new Response(JSON.stringify({
            reply: `¡Listo! He eliminado "${args.delete_item_name}" del menú de ${clientName}.`
          }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });
        }
      }

      // B) CREAR TAREA DE ATENCIÓN A CLIENTES (CS) PARA TRABAJOS EXTERNOS
      if (fnName === "create_cs_task") {
        const dueDate = new Date();
        dueDate.setDate(dueDate.getDate() + 5);

        await supabase.from("tragalero_tasks").insert({
          user_id: targetUserId,
          client_name: clientName,
          client_domain: clientDomain,
          title: args.title,
          description: args.description,
          image_url: image_url || null,
          due_date: dueDate.toISOString(),
          status: "Pendiente"
        });

        const formattedDate = dueDate.toLocaleDateString("es-MX", { day: "numeric", month: "long", year: "numeric" });
        return new Response(JSON.stringify({
          reply: `¡Listo! He generado la solicitud de "${args.title}" para ${clientName}. Quedará completada el día ${formattedDate}.`
        }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });
      }
    }

    return new Response(JSON.stringify({
      reply: textReply || "¡Hola! ¿En qué te puedo colaborar hoy?"
    }), { headers: { ...corsHeaders, "Content-Type": "application/json" } });

  } catch (err) {
    return new Response(JSON.stringify({ reply: "Error interno en Edge Function: " + err.message }), {
      status: 200,
      headers: { ...corsHeaders, "Content-Type": "application/json" }
    });
  }
});
```
